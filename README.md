## 📖 Overview

A fully functional, three-mode calculator built with pure HTML, CSS, and 
JavaScript, styled after modern mobile calculator apps — circular keys, a 
clean dark interface, and a signature orange accent. It combines everyday 
arithmetic, advanced scientific functions, and a programmer's number-base 
converter into one consistently-sized, professional interface. Every 
calculation is powered by a custom-built expression parser that correctly 
handles operator precedence — no `eval()` is used anywhere in the app.

---

## ✨ Key Features

- 🔢 **Three calculator modes** — Standard, Scientific, and Programmer, switchable instantly with no page reload
- 🧮 **Custom recursive-descent expression parser** — safely evaluates arithmetic with correct operator precedence, parentheses, and unary operators, without using `eval()`
- 📐 **Scientific functions** — sin, cos, tan (degrees), log, ln, square root, powers (xʸ), factorial, π, and e constants
- 🔁 **Programmer mode number base conversion** — select HEX, DEC, OCT, or BIN, then press `=` to convert the current value into that base on demand
- 🧠 **Memory functions** — M+, M−, MR, MC, with a visual indicator when memory holds a value
- 📋 **Copy-to-clipboard** — one-tap copy of the current result with visual confirmation
- ⌨️ **Full keyboard shortcut support** across all modes
- ⚠️ **Robust error handling** — division by zero, invalid expressions, and domain errors (e.g., log of a negative number) are all caught gracefully
- 🎨 **Consistent circular Material-style UI** — every key is a fixed-size circle across all three modes, so the calculator's shell stays the same size regardless of which mode is active
- 🌗 **Dark/Light theme toggle** — instant switch powered by CSS custom properties, with a signature orange accent in both themes
